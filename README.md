# VALENCE ATELIER — Monolithic Architecture & Sanctuaries

> Bespoke Monolithic Spatial Architecture, Subterranean Pavilions, and Bioclimatic Sanctuaries.  
> Locations: Zurich · Kyoto · Reykjavik · Milan

An ultra-high-end editorial digital experience inspired by modern boutique brutalism, Swiss typographic discipline, Lenis inertial physics, and tactile interaction design.

---

## Highlights

- **Editorial Brutalism & Swiss Typography:** Fluid clamp scale wordmark, paired with `Syne`, `Plus Jakarta Sans`, and `Space Mono` for technical coordinates and parenthetical brackets.
- **Inertial Smooth Scrolling:** Powered by **Lenis Scroll** for weighted boutique momentum.
- **Sticky Stacking Masterwork Deck:** 4 architectural monolith case studies that stack and scale down smoothly on scroll.
- **Scroll-Scrubbed Obsidian Philosophy:** Viewport-pinned text illumination transitioning word-by-word with scroll delta.
- **The Materiality Studio:** Interactive HTML5 canvas with real-time specular roughness shader and lighting vectors across 5 geological mediums (Bush-hammered concrete, Volcanic basalt, Brushed titanium, Charred Yakisugi Hinoki, and Smoked obsidian).
- **Web Audio Spatial Soundscape:** Synthesized 432 Hz binaural gallery acoustic resonance dock with animated wave visualizer.
- **Synchronized Global World Clocks:** Live local time for Zurich (CET), Kyoto (JST), Reykjavik (GMT), and New York (EST).
- **Slide-Over Commission Drawer:** Bespoke intake form with typology tags and validation.
- **Organic Alpine Climax Footer:** Full-bleed moody forest landscape with translucent frosted glass inquiry capsules.

---

## Tech Stack

- **HTML5 & Modern CSS3** (CSS Custom Properties, Glassmorphism, CSS Grid, Fluid Clamp Typography)
- **Vanilla JavaScript (ES6+)** with zero heavy framework overhead
- **Lenis Scroll** for inertial scroll physics
- **Web Audio API** for procedural binaural ambient acoustics
- **HTML5 Canvas 2D / Shader Simulation** for real-time normal lighting and specular sheen
- **Lucide Icons** & **Google Fonts**
